Here is the SPL we created in the last phase. 
```spl
index=* sourcetype="XmlWinEventLog:Security" "<EventID>4625</EventID>"
| bin _time span=10m
| stats count as failed_logins by _time host
| where failed_logins >= 5
```

Now we will turn it into an automated alert.

With the SPL in the search bar, click `Save As` → `Alert`.
