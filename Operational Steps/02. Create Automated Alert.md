Here is the SPL we created in the last phase. 
```spl
index=* sourcetype="XmlWinEventLog:Security" "<EventID>4625</EventID>"
| bin _time span=10m
| stats count as failed_logins by _time host
| where failed_logins >= 5
```

Now we will turn it into an automated alert.

With the SPL in the search bar, click `Save As` → `Alert`.

- Set Title to "Repeat Failed Login Attempts".
- Set Description to "5 or more failed logins within 10minutes or less".
- Keep Permissions as "Private".
  - This is because we are testing the alert for lab purposes.
  - "Shared in App" would be used in a more realistic multi-analyst SOC environment where we want everyone using the Search & Reporting app to have access to the detection.
- Keep Alert type as "Scheduled".
- Keep Expires at "24 hour(s)".
- Keep the alert as trigger whenever the number of results is greater than 0.
