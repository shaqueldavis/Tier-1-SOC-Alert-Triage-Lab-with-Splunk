# Download Splunk

Go to [Splunk's website](https://www.splunk.com/en_us/download.html) and download Splunk Enterprise.
- Start free trial
- Enter email
- Enter account details
- verify your email

Power on linux VM and Windows VM.

Open PowerShell as an administrator on Windows VM and connect to your Ubuntu server (Linux VM) via ssh.
```
ssh <SERVER_NAME>@<IP_ADDRESS>
```
In my case:
```
ssh splunk-server@192.168.113.159
```

<img width="1481" height="143" alt="image" src="https://github.com/user-attachments/assets/f3b41e16-ef52-462c-9d7d-24e7fa5e12c7" />

If you don't remember your IP, login to your Linux VM and execute `hostname -I`.

Execute the wget command.
