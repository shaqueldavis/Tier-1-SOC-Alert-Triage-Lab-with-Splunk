# Download Splunk to Linux

This time we will download the [Splunk Universal Forwarder](https://www.splunk.com/en_us/download/universal-forwarder.html). Choose the `wget` command next to Windows 10/11 and copy it.

<a href="https://www.splunk.com/en_us/download.html"><img src="https://img.shields.io/badge/-Splunk_Universal_Forwarder-FF1493?&style=for-the-badge&logo=Splunk&logoColor=white" /></a>

Open an administrator PowerShell window on your Windows VM and paste in the command. 
```
wget -O splunkforwarder-10.4.2-33c3bf42cd73-windows-x64.msi "https://download.splunk.com/products/universalforwarder/releases/10.4.2/windows/splunkforwarder-10.4.2-33c3bf42cd73-windows-x64.msi"
```
Confirm that the URL and file name here match the one from the splunk website.

You can alternatively use PowerShell's native command:
```powershell
Invoke-WebRequest `
-Uri "https://download.splunk.com/products/universalforwarder/releases/10.4.2/windows/splunkforwarder-10.4.2-33c3bf42cd73-windows-x64.msi" `
-OutFile ".\splunkforwarder-10.4.2-33c3bf42cd73-windows-x64.msi"
```
The native command will require you to rearrange the code. This can be typed on one line. The back ticks that separate it on multiple lines are for readability.

Confirm it downloaded. Enter the command below and hit tab to auto complete.
```powershell
Get-ChildItem .\splunkforwarder
```
If it doesn't auto complete use `Get-ChildItem .\splunkforwarder*`.

Install the file:

First move the command out of the `system32` folder and into the `Downloads` folder.
```powershell
Move-Item ".\splunkforwarder-10.4.2-33c3bf42cd73-windows-x64.msi" "$env:USERPROFILE\Downloads\"
```

Switch to the `Downloads` folder.
```powershell
cd "$env:USERPROFILE\Downloads"
```

Confirm it has been moved:
```powershell
Get-ChildItem splunkforwarder*.msi
```

Now install the file:
```powershell
msiexec.exe /i "C:\Users\<USER-FOLDER-HERE>\Downloads\splunkforwarder-10.4.2-33c3bf42cd73-windows-x64.msi"
```
> [!NOTE]
> I recommend using the absolute path or you may receive an error message.
> Replace <USER-FOLDER-HERE> with your user folder. after `\Users\` begin type the first two letters of your username and hit tab to auto compleat.
