# Download Splunk to Linux

This time we will download the [Splunk Universal Forwarder](https://www.splunk.com/en_us/download/universal-forwarder.html). Choose the `wget` command next to Windows 10/11 and copy it.

Open an administrator PowerShell window on your Windows VM and paste in the command. (I will not provide it here in case it changes over time.)
