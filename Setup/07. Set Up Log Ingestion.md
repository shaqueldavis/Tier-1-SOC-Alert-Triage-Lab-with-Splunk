# Set Up Log Ingestion

We already configured where the Universal Forwarder sends data. Now we will tell it what data to collect with the inputs.conf file.

for this lab we will ingest:
- Windows Security logs
- Sysmon logs
- PowerShell Operational logs


### 1. Configure `inputs.conf`

Check whether inputs.conf already exists:
```powershell
Test-Path "C:\Program Files\SplunkUniversalForwarder\etc\system\local\inputs.conf"
```

We're using `Test-Path` instead of `Get-ChildItem` because it produces cleaner output.

Put the following into the file, then save and close it:

```ini
[WinEventLog://Security]
disabled = 0
start_from = oldest
current_only = 0
renderXml = true

[WinEventLog://Microsoft-Windows-Sysmon/Operational]
disabled = 0
start_from = oldest
current_only = 0
renderXml = true

[WinEventLog://Microsoft-Windows-PowerShell/Operational]
disabled = 0
start_from = oldest
current_only = 0
renderXml = true
```

each of these 3 blocks of code are called a stanza. To sum up the meaning, the first stanza essentially means:
- Collect the Windows Security event log
- Turn collection on
- start from the oldest available events
- Include existing events rather than only new events
- collect the events in XML format

The only detail that changes in each stanza is the first line, where the collected logs are coming from.

### 2. What each input provides

#### Windows Security `[WinEventLog://Security]`

This is where you'll get events such as:
- 4624 — Successful logon
- 4625 — Failed logon
- 4720 — User account created
- 4728/4732 — User added to a group

#### Sysmon `[WinEventLog://Microsoft-Windows-Sysmon/Operational]`

This provides richer endpoint telemetry such as:
- Event ID 1  — Process creation
- Event ID 3  — Network connection
- Event ID 11 — File creation

#### PowerShell `[WinEventLog://Microsoft-Windows-PowerShell/Operational]`

This gives you PowerShell telemetry, including the events we'll eventually use for things like:
- 4104 — PowerShell Script Block Logging


### 3. Verify Splunk sees the configuration correctly

Enter the following commands individualy. They should return results containing the settings we just included in the inputs.conf file.
```powershell
& "C:\Program Files\SplunkUniversalForwarder\bin\splunk.exe" btool inputs list "WinEventLog://Security"
```
```powershell
& "C:\Program Files\SplunkUniversalForwarder\bin\splunk.exe" btool inputs list "WinEventLog://Microsoft-Windows-Sysmon/Operational"
```
```powershell
& "C:\Program Files\SplunkUniversalForwarder\bin\splunk.exe" btool inputs list "WinEventLog://Microsoft-Windows-PowerShell/Operational"
```

The important part we are looking for is:
- current_only = 0
- disabled = 0
- renderXml = true
- start_from = oldest

These are the settings we just configured. These commands confirm that Splunk is actually using these settings.
