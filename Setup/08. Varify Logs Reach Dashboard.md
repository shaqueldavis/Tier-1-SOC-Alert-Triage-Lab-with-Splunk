# Varify Logs Reach Dashboard.md

Open PowerShell as an administrator if you haven't already on the Windows VM.

Get the Windows VM's hostname:
```powershell
$env:COMPUTERNAME
```

This value will normally become the Splunk host field for events coming from the Windows VM endpoint.

Before checking Splunk, let's make sure each log source actually contains data.
```powershell
Get-WinEvent -LogName Security -MaxEvents 5
```
```powershell
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 5
```
```powershell
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 5
```

As long as these commands return events, Windows has telemetry available for the Universal Forwarder to collect.
