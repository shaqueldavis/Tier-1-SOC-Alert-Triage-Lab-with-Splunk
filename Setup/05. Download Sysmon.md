# Download Sysmon

To download and configure Sysmon, follow the steps documented in my [SOC_Automation/Project Phases/Sysmon](https://github.com/shaqueldavis/SOC_Automation/blob/main/Project%20Phases/07.%20Sysomon.md) file, then return here after. Follow these steps on your Windows VM.

<a href="https://github.com/shaqueldavis/SOC_Automation/blob/main/Project%20Phases/07.%20Sysomon.md"><img src="https://img.shields.io/badge/-Sysmon_Download_Guide-0072b1?&style=for-the-badge&logo=Sysmon&logoColor=white" /></a>

Once you have Sysmon, installed check to make sure you're actually seeing events. Go the start menu, search for and open Event Viewer, then follow the path below in the left pane:
```path
Event Viewer
  └─ Applications and Services Logs
      └─ Microsoft
          └─ Windows
              └─ Sysmon
                  └─ Operational
```
