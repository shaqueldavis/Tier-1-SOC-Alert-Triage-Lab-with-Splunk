# Install Windows Client 

To download, install, and configure the Windows 11 VM, follow the steps outlined in the links below.

> [!NOTE]
> Use the configuration below for this lab's setup not the one in the link. The only difference should be the amount of memory allotted.

- Hostname:    windows-endpoint
- Disk:        64 GB, thin provisioned
- Memory:      4 GB
- Processors:  2 vCPUs
- Network:     VMware NAT
